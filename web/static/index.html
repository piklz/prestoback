How self-update works
1
Checks DockerHub registry digest via API (no download)
2
If different: pulls new image, drains active jobs (max 60s)
3
Spawns a detached helper container via Docker socket
4
Helper force-removes this container then starts new one with same flags + labels
5
PrestoBack is back up in ~15s — config, backups, and compose ownership untouched
After clicking Update, this page will briefly disconnect. Wait ~20s then refresh. If PrestoBack doesn't return, check: docker logs prestoback-updater
